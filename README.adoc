== Über das Projekt
Dieses Repository enthält einen Implementierungsleitfaden für Hersteller von Apps für Versicherte.
Da eine App für die genannte Zielgruppe verschiedenen Fachmodule inkludieren kann, die jeweils mit eigenen Backend-Services kommunizieren, werden diese von dieser Dokumentation als eigene Module aufgegriffen.

=== Getting Started
Die versionierte Dokumentation ist in Form von github-pages unter https://gematik.github.io/ig-versicherten-app/ einsehbar.
Diese enthält allgemeine Hinweise zur Einbindung des Zero-Trust SDKs und zur generellen Umsetzung von z.B. Barrierefreiheit und User Experience.
